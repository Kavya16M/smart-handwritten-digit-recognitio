About

About the Project

This project explores multiple machine learning and deep learning approaches for handwritten digit recognition.

Logistic Regression, Support Vector Machine, Random Forest, Neural Network and CNN models were trained and evaluated using classification metrics.

The CNN achieved the highest test accuracy of 99.06% and was selected for integration with the Flask web application.

Dataset

MNIST Handwritten Digit Dataset

The project uses the MNIST dataset containing grayscale handwritten digit images from 0 to 9.

About MNIST

MNIST is a widely used benchmark dataset for handwritten digit recognition. Each sample is a grayscale image with a size of 28 × 28 pixels.

The dataset contains 60,000 training images and 10,000 testing images distributed across ten digit classes.
